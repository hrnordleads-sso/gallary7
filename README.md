# gallary7

**Diet Soda** — Pure Zero Refreshment. Gallery site 07.

Interactive 3D beverage landing page with flavor switching, parallax berries, and rising bubbles.

## Live

https://hrnordleads-sso.github.io/gallary7/

## Local

Serve the folder over HTTP (model-viewer needs a server), e.g.:

```bash
npx serve . -l 5177
```

3D models, textures, and product PNGs are vendored under `assets/` for GitHub Pages reliability. CDN copies remain as fallbacks if a local file fails.

## Favicon

`favicon.svg` / `favicon.png` / `favicon.ico` at the site root (works with `/gallary7/` Pages paths).
